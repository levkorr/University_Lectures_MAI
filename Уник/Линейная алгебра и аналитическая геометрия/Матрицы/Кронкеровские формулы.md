##### Кронкеровское произведение

A = ( m x n ), B = ( p x q )
A $\otimes$ B = ( m⋅p x n⋅g )

$A \otimes B = \begin{pmatrix}a_{11}⋅B&...&a_{1n}⋅B\\...&...&...\\a_{m1}⋅B&...&a_{mn}⋅B\\\end{pmatrix}$
Пример:
A = $\begin{pmatrix}1&2\\3&4\\\end{pmatrix}$, B = $\begin{pmatrix}0&5\\6&-1\\\end{pmatrix}$
##### Кронкеровская сумма

A = ( m x m ), B =  ( n x n )
A $\oplus$ B = A $\otimes$ E + E $\otimes$ B

$A = \begin{pmatrix}1&2\\3&4\\\end{pmatrix}$, $B = \begin{pmatrix}0&5\\6&-1\\\end{pmatrix}$

$A \otimes E = \begin{pmatrix}1&0&2&0\\0&1&0&2\\3&0&4&0\\0&3&0&4\\\end{pmatrix}$ 

$E \otimes B = \begin{pmatrix}0&5&0&0\\6&-1&0&0\\0&0&0&5\\0&0&6&-1\\\end{pmatrix}$ 

$A \oplus B = \begin{pmatrix}1&5&2&0\\6&0&0&2\\3&0&4&5\\0&3&6&3\\\end{pmatrix}$
