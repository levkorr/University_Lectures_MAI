1. Прямоугольная (m⋅n)

$A = \begin{pmatrix}2&3\\0&-4\\1&5\\\end{pmatrix}$

2. Квадратная (n⋅n) - n-го порядка

$A = \begin{pmatrix}a_{11}&...&a_{1n}\\...&...&...\\a_{n1}&...&a_{nn}\\\end{pmatrix}$

a<sub>11</sub> **→** a<sub>nn</sub> - главная диагональ
a<sub>1n</sub> **→** a<sub>n1</sub> - побочная диагональ

3. Диагональная (n⋅n) - элементы только на главной диагонали, остальное нули

$Λ = \begin{pmatrix}λ&0\\0&λ\\\end{pmatrix}$   λ ∈ ℤ

4. Единичная (n⋅n) - на главной диагонали единицы,  остальное нули

$E = \begin{pmatrix}1&0\\0&1\\\end{pmatrix}$

5. Нулевая (m⋅n) - все элементы нули

$O = \begin{pmatrix}0&0\\0&0\\\end{pmatrix}$ $≠\begin{pmatrix}0&0&0\\0&0&0\\\end{pmatrix}$

6. Верхняя треугольная (n⋅n) - элементы ниже главной диагонали нули

$U = \begin{pmatrix}5&6&0\\0&-3&4\\0&0&8\\\end{pmatrix}$

7. Нижняя треугольная (n⋅n) - элементы выше главной диагонали нули

$A = \begin{pmatrix}5&0&0\\4&1&0\\0&2&8\\\end{pmatrix}$

8. Матрица-столбец - (m⋅1) - 1 стобец

$A = \begin{pmatrix}8\\-2\\-5\\\end{pmatrix}$

9. Симметрическая (n⋅n) - $A^{T} = A$

$А = \begin{pmatrix}1&2&3\\2&4&5\\3&5&6\\\end{pmatrix}$ - симметрична по главной диагонали

10. Кососимметрическая (n⋅n) - $A^{T} = -A$

$A = \begin{pmatrix}1&2&-3\\-2&4&-5\\3&5&6\\\end{pmatrix}$ - симметрична по главной диагонали с разными знаками
