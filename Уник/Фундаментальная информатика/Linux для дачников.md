Операционная система UNIX:
1. Многопользовательская многозадачная ОС
2. Создана в 1969-1973г
3. Авторы - Ken Thompson, Dennis Ritchie, Brian Kernighan
4. Основана на пинципах Философии UNIX
   Каждая программа должна делать что-то одно и делать это хорошо
   Вывод каждой программы может быть использован как ввод для другой. Программы должны уметь работать вместе
   Программы должны ориентироваться на текстовый ввод-вывод, являющийся универсальным форматом

Linux (GNU/Linux):
1. Ядро Linux, Линус Торвальдс, 1991
2. Системная библиотека (glibc), компилятор C (gcc) и основные утилиты окружения - проект GNU, Ричард Столлман, 1983
3. У автора (Филимонов) имеется образ виртуалки с Linux 0.99p11, первая версия SLS Linux (будущая Slackware), 1993
4. Появление свободного от лицинзионных ограничений ядра стало катализатором массового производства дистрибутива Linux
5. Листрибутив как способ упаковки программ (пакетов) и философии (набора религиозных верований ) установки.

UNIX база:
1. В любой UNIX-системе есть файл:
   Стандартный ввод: stdin -fd 0
   Стандартный вывод: stdout -fd 1
   Любые блочные и символьные устройства (внутри /dev)
   любые сведения о системе (внутри /proc)
   Даже оперативная память (внутри /dev/mem и /dev/kmem)
2. Файлы на одном физическом устройстве организованы в файловую систему
3. Все файловые системы смонтированы в общую иерархию, начинающуюся с корня (root), он же /
4. В интерактивном терминале запущен shell (bash в случае Ubuntu)
5. bash является наследником Bourne Shell (sh) и является полным по Тьюрингу языком программирования
6. В \*BSD традиционно вместо bash используется C Shell (csh)
7. Особые символы должны экранизироваться при использовании в именах файлов
