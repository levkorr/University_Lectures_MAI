#### №1 \*
**Условие:**
Входное слово представляет собой два троичных числа без знака, разделенные знаком "+". Составить алгоритм вычисления суммы этих чисел.
**Алгоритм:**
```
>0  -> 0>  
>1  -> 1>  
>2  -> 2>  
>+  -> <+  
2<  -> 1)  
1<  -> 0)  
0<  -> ]2  
0]  -> ]2  
1]  -> )0  
2]  -> )1  
]2  -> ]  
]+  =>  
)01 -> 0)1  
)02 -> 0)2  
)0  -> )  
)1  -> 1)  
)2  -> 2)  
)+  -> +(  
(0  -> 0(  
(1  -> 1(  
(2  -> 2(  
(   -> [  
+[  -> <+  
0[  -> *1  
1[  -> *2  
2[  -> {0  
2{  -> {0  
1{  -> *2  
0{  -> *1  
{   -> *1  
2*  -> *2  
1*  -> *1  
0*  -> *0  
+*  -> <+  
    -> >
```
**Объяснение:**
1. Со знаком > доходим до +  
2. Знак меняется на <, который означает вычитание 1  
3. Если от цифры нельзя отнять 1, знак становится ] , что означает вычитание из след цифры
4. После успешно вычитания знак становится )  
5. Со знаком ) указатель доходит до + и меняется на (  
6. Со знаком ( указатель до кона правого числа  
7. Указатель меняется на \[ , который означает +1  
8. Если после +1 нужно добавить 1 к след цифре используется {  
9. После успешного сложения указатель становится *  
10. Со * указатель доходит до + и запускает новый цикл  
11. Концом программы является ситуация когда слева остается 0, который меняется на ]2 , потом на ]  
P. S. В программе также используется удаление ведущих нулей слева

#### №3 \*
**Условие:**
Входное слово представляет собой троичное число без знака. Составить алгоритм копирования числа. Результат должен состоять из исходного слова и его копии, разделенных знаком "="
**Алгоритм:**
```
*0 -> 0*  
*1 -> 1*  
*2 -> 2*  
*  -> =  
  
A0 -> 0A  
A1 -> 1A  
A2 -> 2A  
A= -> =A  
A  -> 0  
  
B0 -> 0B  
B1 -> 1B  
B2 -> 2B  
B= -> =B  
B  -> 1  
  
C0 -> 0C  
C1 -> 1C  
C2 -> 2C  
C= -> =C  
C  -> 2  
  
#0 -> 0#A  
#1 -> 1#B  
#2 -> 2#C  
#= => =  
  
   -> #*
```
**Объяснение:**
1. Алгоритм копирует троичное число и ставит между числом и его копией знак =  
2. Сначала правило  -> *  добавляет * в начало числа, 
3. потом правила  \*0 -> 0*, \*1 -> 1*, \*2 -> 2*  двигают * вправо в конец
4. после * -> = заменяет его на =  
5. Дальше используется символ #, который по очереди проходит по исходному числу слева направо 
6. Правила  #0 -> 0#A, #1 -> 1#B, #2 -> 2#C  запоминают текущую цифру: A - это 0, B - 1, C - 2  
   Например, если встретилась 1, получается #1 -> 1#B. Сам символ B потом двигается вправо через оставшиеся цифры и равно правилами  B0 -> 0B, B1 -> 1B, B2 -> 2B, B= -> =B
   Когда B доходит до конца, правило B -> 1 возвращает запомненную цифру 1 уже после =.
   Поэтому исходное число постепенно копируется справа от = 
7. В конце, когда # доходит до =, применяется терминальное правило  #= => =,  и алгоритм останавливается 
8. В итоге получаем исходное число, знак = и его копию

#### №8 \*
**Условие:**
Входное слово представляет собой два троичных числа без знака, разделенные знаком ">". Составить алгоритм вычисления троичного логического сдвига первого числа вправо на число разрядов второго числа.
**Алгоритм:**
```
0z -> z0
1z -> z1
2z -> z2
z  -> 0
0f -> f
1f -> f
2f -> f
>f =>
?0 -> 0?
?1 -> 1e
?2 -> 2e
?  -> f
e0 -> 0e
e1 -> 1e
e2 -> 2e
e  -> d
0d -> d2
1d -> 0s
2d -> 1s
0s -> s0
1s -> s1
2s -> s2
>s -> l>
0l -> z
1l -> z
2l -> z
>l -> 0>
>  -> >?
```
**Объяснение:**
1. Создаем указатели:
   \> — это каретка-разделитель между числом (слева) и счетчиком сдвигов (справа).
   ? — маркер, который бежит в самый конец счетчика, уменьшает его на 1 (правила e/d/s) и возвращается как s.
   l — маркер, который активируется, когда счетчик успешно уменьшен на 1. Он идет влево (вглубь числа) и заменяет крайнюю правую цифру числа на маркер z.
   z — маркер сдвига. Он «бежит» влево до самого начала строки, превращая каждую цифру по пути в ноль (или сдвигая их), и в итоге восстанавливает структуру.
   f — маркер очистки счетчика. Когда счетчик доходит до 0, f стирает оставшиеся нули счетчика и сам знак >.
2. Вся логика строится на циклическом повторении трех шагов, пока счетчик не обнулится:
   Уменьшение счетчика: Сначала от каретки > в самый правый конец строки отправляется маркер поиска ?. Пробегая через цифры счетчика, он превращается на конце строки в маркер вычитания d и уменьшает счетчик на единицу по правилам классического троичного вычитания. После этого маркер возврата s бежит обратно влево к каретке.
   Удаление разряда числа: Как только сигнал успешного вычитания s утыкается в каретку (>s), он превращается в маркер сдвига l. Этот маркер делает один шаг влево, «съедает» самую правую цифру исходного числа (0l/1l/2l) и превращается в маркер заполнения z.
   Заполнение нулями слева: Появившийся маркер z транзитом бежит через все оставшиеся цифры числа в самый левый край строки. Достигнув начала строки, z превращается в 0, тем самым компенсируя удаленный разряд и сдвигая число вправо. После этого каретка > снова активирует маркер ? для следующей итерации.
3. Когда счетчик справа полностью исчерпан (превратился в нули), маркер ? на конце строки не находит значащих цифр и трансформируется в маркер зачистки f. Этот маркер последовательно стирает все нули счетчика справа налево , доходит до каретки и полностью уничтожает ее через терминальное правило, останавливая программу и оставляя на экране сдвинутое число

**Условие:**
Входное слово представляет собой два двоичных числа без знака, разделенные знаком "$". Составить алгоритм выделения разрядов второго числа по маске, в качестве которой используется первое число.
**Алгоритм:**
```
$   -> #@  
@0  -> 0@  
@1  -> 1@  
@   -> |  
0#  -> &A  
1#  -> &B  
0A| -> C|  
1A| -> C|  
A|  -> C|  
A0  -> 0A  
A1  -> 1A  
0B| -> C|0  
1B| -> C|1  
B|  -> C|0  
B0  -> 0B  
B1  -> 1B  
0C  -> C0  
1C  -> C1  
&C  -> #  
#   ->  
|   =>  
    -> >
```
**Объяснение:**
Исходная запись содержит два двоичных числа, разделённых символом `$`.  
1. `$` заменяется на `#` и `@`.  
2. `@` проходит по первому числу до конца и ставит вертикальную черту `|`.  
3. `#` начинает просмотр маски:  `0` заменяется на `&a`;  `1` заменяется на `&b`.

5. Если встретились любая цифра и `a`, выполняется переход к `c|`: бит отбрасывается, поскольку в маске стоял ноль.  
6. Если `b` достигает конца числа, возникают конфигурации `0b|` или `1b|`. Бит переносится за вертикальную черту:
