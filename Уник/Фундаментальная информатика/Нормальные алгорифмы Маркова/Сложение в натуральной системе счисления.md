В натуральной системе счисления каждое n = (N+1) * I

| n   | (N+1) * I |
| --- | --------- |
| 0   | I         |
| 1   | II        |
| 2   | III       |
| ... | ...       |

Сложение в натуральной системе счисления через НАМ:
До: III+IIIII
Функция: `+I ⇒ `
Результат: IIIIIII

III = 2, IIIII = 4, IIIIIII = 6
