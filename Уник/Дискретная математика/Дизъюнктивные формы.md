$n$ - число переменных (n ∈ ℕ)
$x_{j}$ ∈ { 0, 1 }, $j$ ∈ { 1, 2, ..., n }
Будем рассматривать выражение вида $x_{k_{1}}^{\sigma_{k_{1}}}⋅x_{k_{2}}^{\sigma_{k_{2}}}⋅...⋅x_{k_{l}}^{\sigma_{k_{l}}}$ , где $l$  ∈ {1, ..., n}, $k_{j}$ ∈ {1, ..., n}
$x_{k_{j}}^{\sigma_{k_{j}}} = \begin{cases} \overline{x}_{k_{j}} \ , при \ \sigma_{k_{j}} =0 \\ {x}_{k_{j}} \ , при \ \sigma_{k_{j}} =1 \end{cases}$

Примеры выражений:
при $n = 4$
выражения: $x_{1}, \ x_{2}⋅x_{3}, \ x_{3}⋅x_{4}, \ x_{1}⋅x_{2}⋅x_{3}⋅x_{4}$

Выражение заданного вида $x_{k_{1}}^{\sigma_{k_{1}}}⋅x_{k_{2}}^{\sigma_{k_{2}}}⋅...⋅x_{k_{l}}^{\sigma_{k_{l}}}$ называется **элементарной конъюнкцией**
**Дизъюнктивной конъюнкцией** называется конечная сумма (дизъюнкция) элементарных конъюнкций, которые различны.
**Совершенной дизъюнктивной нормальной формой** называется дизъюнктивная нормальная форма в которой каждая элементарная конъюнкция содержит n нормальных переменных

Примеры дизъюнктивных нормальных форм:
1. $f(x_{1}, \ x_{2}, \ x_{3}, \ x_{4}) = x_{1}+x_{2}⋅x_{4}+\overline{x}_{3}⋅x_{4} + x_{1}⋅ x_{2}⋅ x_{3}⋅ x_{4}$ - дизъюнктивная нормальная форма
2. $g(x_{1}, \ x_{2}, \ x_{3}) = x_{1}⋅x_{2}⋅x_{3}+\overline{x}_{1}⋅x_{2}⋅\overline{x}_{3} + x_{1}⋅ x_{2}⋅ x_{3}$ - совершенная дизъюнктивная нормальная форма

**dnf** - дизъюнктивная нормальная форма
**sdnf** - совершенная дизъюнктивная нормальная форма


Пусть $f(x_{1}, \ x_{2}, ..., \ x_{n})$ - функция от $n$ переменных:
$f: \{0; \ 1\}^{n} → \{0;1\}$
Пусть $α = (α_{1}, \ α_{2}, ..., \ α_{n})\ ∈ \  \{0; \ 1\}^{n}$ конкретный набор значений
Рассмотрим значение $f$ на  конкретном наборе:
$f(α_{1}, \ α_{2}, ..., \ α_{n}) = α_{1} ⋅ f(1, \ α_{2}, ..., \ α_{n})+ \overline{α}_{1} ⋅ f(0, \ α_{2}, ..., \ α_{n}) =$ $=α_{1} ⋅ α_{2}⋅ f(1,\ 1, \ α_{3}, ..., \ α_{n}) + \overline{α}_{1} ⋅ \overline{α}_{2}⋅ f(0,\ 0, \ α_{3}, ..., \ α_{n}) +\overline{α}_{1} ⋅ {α}_{2}⋅ f(0,\ 1, \ α_{3}, ..., \ α_{n}) + \overline{α}_{1} ⋅ \overline{α}_{2}⋅ f(1,\ 0, \ α_{3}, ..., \ α_{n})$
##### Теорема: 
Пусть $f: \{0; \ 1\}^{n} → \{0;1\}$
Тогда: $f(x_{1}, \ x_{2}, ..., \ x_{n}) = + \ x_{1}^{\sigma_{1}} \  ⋅ x_{2}^{\sigma_{2}} \  ⋅ \ ... \ ⋅ \ x_{n}^{\sigma_{n}} \ ⋅ \ f(\sigma_{1}, \ \sigma_{2}, \ ...,\ \sigma_{n}), где \ \sigma_{j}\ ∈ \{0;1\} ,\ j ∈ \{1, \ ..., \ n\}$
