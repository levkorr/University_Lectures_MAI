Набор операций называется функционально полной системой операций, если любая функция может быть представлена формой, в которой содержатся операции только из этого набора.
Набор операций {+ ; ⋅ ; $\overline{}$ } - функционально полная система операций, т.к. из этого набора можно создать все остальные операции

Пример:
1. { ⋅; $\overline{}$ } - конъюкционный базис
   Реализуем + : $a + b \ = \ \overline{\overline{a + b}} \ = \ \overline{\overline{a} ⋅ \overline{b}}$
2. { ⋅ ; $⊕$ ; 1}  
   Реализуем $\overline{}$ :  $\overline{x}=x⊕1$
   Реализуем + : $a+b \ = \ \overline{a}b ⊕ a\overline{b} ⊕ ab \ = \ (a⊕1)b⊕a(b⊕1)⊕ab \ = \ ab⊕b⊕ab⊕a⊕ab \ = \ a⊕b⊕ab$

В sdnf только одно из значений может иметь значение 1 ⇒ Все + в sdnf можно заменить на $⊕$
