1. Коммутативность 
   ∀xy:
   `x + y = y + x`
   `x ⋅ y = y ⋅ x`
2. ∀x:
   `x + x = x`
   `x ⋅ x = x`
3. Ассоциативность 
   ∀xyz:
   `( x + y ) + z = x + ( y + z )`
   `( x ⋅ y ) ⋅ z = x ⋅ ( y ⋅ z )`
4. Дистрибутивность
   ∀xyz:
   `x ⋅ ( y + z ) = x ⋅ y + x ⋅ z`
   `x + x ⋅ y = x`
5. Двойное отрицание
   ∀x:
   `not( not( x ) ) = x`
6. Закон де Моргана
   ∀x:
   `not( x + y ) = not x ⋅ not y`
   `not( x ⋅ y ) = not x + not y`
7. ∀x:
   `x ⋅ 0 = 0`
   `x + 0 = x`
   `x + 1 = 1`
   `x ⋅ 1 = x`
   `x + not x = 1`
   `x ⋅ not x = 0`
8. Поглощение
   ∀xy:
   `x + x̄ ⋅ y = x + y`
