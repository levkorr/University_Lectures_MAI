
1. Отрицание - инверсия (~ x; x̄; not x; не x)
2. Конъюнкция - логическое умножение (x & y; x ⋅ y; x and y; x и y)
3. Дизъюнкция - логическое сложение (x + y; x or y; x или y)
4. Исключительное или - строгая дизъюнкция (x xor y; x ^ y; x ⊕ y; x + y mod 2)
   `x xor y := x ⋅ not y + not x ⋅ y`
   Выдает значение 1 для различных x и y
   Выдает значение 0 для одинаковых x и y
5. Эквиваленция (x ≡ y)
   `x ≡ y := not( x xor y ) = x ⋅ y + not( x ⋅ y )` 
6. Импликация - следствие (x → y)
   `x → y := x̄ + y`
7. Коимпликация - не следствие (x  ̸→ y)
   `x ̸→ y := not( x → y ) = x ⋅ not y`
8. Штрих Шифера (x | y; x nand y)
   `x | y = not ( x * y )`
9. Стрелка Пирса (x ↓ y; x nor y)
   `x ↓ y = not ( x + y )`
