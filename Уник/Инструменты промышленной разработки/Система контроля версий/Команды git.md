
##### Настройка и инициализация
1. git init - создаёт новый локальный репозиторий .git
2. git clone https://github.com/... - копирует существующий удалённый репозиторий
##### Работа с изменениями
1. git status - возвращает состояние рабочего каталога: какие файлы изменены, добавлены, не отслеживаются.
2. git add name.py - добавляет файл в индекс - то, что будет включено в следующий коммит
3. git commit -m "Сообщение" - фиксирует изменения
4. git diff - показывает разницу между версиями
##### Работа с ветвями
1. git merge - объединяет указанную ветку с текущей
2. git branch - команда используется для управления ветками, c её помощью можно создавать, удалять и перечислять ветки
3. git rebase - позволяет перенести или "переписать" серию коммитов из одной ветки в другую, сохраняя линейную историю
##### Работа с удаленными репозиториями
1. git pull <имя> <ветка> - одновременно скачивает изменения и сливает их с локальной веткой
2. git push <имя> <ветка> - отправляет локальные изменения в удалённый репозиторий
