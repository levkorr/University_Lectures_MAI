ℂ = { (x,y) : x ∈ ℝ } x ∈ ℝ ⇒ x = (x, 0) ∈ ℂ
$z = (x,y)$ - комплексное число; х - реальная часть, y - мнимая
$z = x+iy$ 

Операции с комплексными числами:
1. $z_{1}+z_{2}$ = ($x_{1}, y_{1}$) + ($x_{2}, y_{2}$) = ($x_{1}+x_{2}$, $y_{1}+y_{2}$)
2. $z_{1}⋅z_{2}$ =  ($x_{1}, y_{1}$) ⋅ ($x_{2}, y_{2}$) = ($x_{1}⋅x_{2}-y_{1}⋅y_{2}, x_{1}⋅y_{2}+x_{2}⋅y_{1}$)
3. $\overline{z} = \overline{(x,y)} = (x, -y)$
4. $\frac{z_{1}}{z_{2}} = \frac{z_{1}⋅\overline{z_{2}}}{z_{2}⋅\overline{z_{2}}}$ 

$(0,1) ⋅ (0,1) = (-1,0) = -1 ∈ ℝ$
$(0,1) = i$ - мнимая единица
$i^{2} = -1$

$|z| = \sqrt{x^{2}+y^{2}}$  - модуль комплексного числа
φ - $Arg z$ - аргумент комплексного числа
$Arg z = arg z + 2\pi k, k ∈ ℤ$ 
$argz$ - главный аргумент комплексного числа

$argz = \begin{cases} arctg(\frac{y}{x}), x>0 \\ arctg(\frac{y}{x})+\pi, x<0,y>0 \\ arctg(\frac{y}{x})-\pi, x<0,y<0 \\ \frac{\pi}{2},x=0,y>0 \\ -\frac{\pi}{2},x=0,y<0 \end{cases}$

$\begin{cases} x = |z| ⋅ cos(φ) \\ y = |z| ⋅ sin(φ)\end{cases}$

$z = |z| ⋅ (cos(φ) + i⋅sin(φ))$ - тригонометрическая запись числа

$Arg(z_{1}⋅z_{2}) = Argz_{1}+Argz_{2}$

$z^{n} = |z|^{n} ⋅ (cos(nφ)+i⋅sin(nφ)), n ∈ ℕ$
$\sqrt[n]{z} = \sqrt[n]{|z|} ⋅ (cos(\frac{φ+2\pi k}{n}) + i ⋅ sin(\frac{φ+2\pi k}{n})), n ∈ ℕ, k = \overline{0,n-1}$
