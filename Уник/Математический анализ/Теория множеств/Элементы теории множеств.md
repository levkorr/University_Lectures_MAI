**Множество** - набор объектов произвольной природы

**Элементы множества** - объекты принадлежащие множеству
Если А - множество, а х - его элемент, то **х ∈ А** (х принадлежит множеству А)
Если А - множество, а х не является его элементом, то **х ∉ А** (х не принадлежит множеству А)

Множество B называется **подмножеством** множества А, если каждый элемент множества B принадлежит множеству А. **B ⊂ A**
В ⊂ А ⇔ ∀х ∈ B ⇒ х ∈ А

Множества А и В - **равные**, если  B ⊂ A и А ⊂ В

**∅** - **Пустое множество** - множество, которое не содержит элементов.
∅ ⊂ A, где A - любое множество

**Разностью** **множеств** А и В называется множество С, такое, что для любого х ∈ С выполняется х ∈ А и х ∉ В
А \ B = { x : x ∈ А, x ∉ В }

Если элементы множества А удовлетворяют свойству, то
A = { x : свойство }
Примеры:
A = { n : n = k^2, k ∈ ℕ } = {1, 4, 9, 16, ...}

**Пересечение множеств** А и В называется такое множество С, что х ∈ С ⇔ x ∈ А и x ∈ B
A ∩ В = { x : x ∈ А и x ∈ В }

**Объединение множеств** А и В называется такое множество С, что х ∈ С ⇔ x ∈ А или x ∈ B
A ∪ В = { x : x ∈ А или x ∈ В }
