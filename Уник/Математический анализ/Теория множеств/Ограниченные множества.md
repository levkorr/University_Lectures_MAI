Пусть Х ∈ ℝ:

Множество Х называется **ограниченным сверху (снизу)**, если ∃а ∈ ℝ : x ≤ a (x ≥ a), ∀x ∈ X
Пример:
Х = ( -∞ ; 3 ) ⇒ Х - множество, ограниченное сверху, a = 3

Множество Х называется **ограниченным**, если оно ограниченно и сверху и снизу
Х ⊂ ( a ; b ] = { x : a < x ≤ b }

##### Точная верхняя грань множества Х

Наименьшее из чисел, ограниченного сверху множества Х ∈ ℝ называется **точной верхней гранью множества** Х. Обозначение - Sup X (Supremum)
Если Х не ограничено сверху, то Sup X = +∞

1. x ≤ β, ∀x ∈ Х
2. ∀β' < β ∃х' ∈ Х : β' < х'


1. x ≤ β, ∀x ∈ Х
2. ∀ε>0 ∃x<sub>ε</sub> : x<sub>ε</sub> > β - ε

**ε** - Любое положительное число

Пример:
Sup ( 0 ; 1 ] = max ( 0 ; 1 ] = 1
Sup ( 0; 1 ) = 1, но max ( 0; 1 ) не существует

##### Точная нижняя грань множества Х

Наибольшее из чисел ограничивающих снизу множество Х называется **точной нижней гранью множества** Х. Обозначение - inf X (Infimum)
Если Х не ограничено снизу, то Inf X = -∞

1. α ≤ х, ∀x ∈ Х
2. ∀α' > α ∃х' ∈ Х : х' < α'


3. α ≤ х, ∀x ∈ Х
4. ∀ε>0 ∃x<sub>ε</sub> : x<sub>ε</sub> < α + ε

Пример:
Inf \[ -2 ; 3 ) = -2 = min \[ -2 ; 3 )
Inf ( -2; 3 ) = -2, но min ( -2; 3 )  не существует
