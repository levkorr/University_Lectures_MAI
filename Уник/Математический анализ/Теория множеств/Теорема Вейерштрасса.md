Всякое непустое ограниченное сверху (снизу) числовое множество имеет единственную точную верхнюю (нижнюю) грань

Док-во:

Пусть Х ⊂ ℝ, Х - ограниченное сверху множество, Х ≠ ∅
Y = { y : Y ∈ ℝ, y ограничивает сверху Х }
Y ≠ ∅ по условию
Из определения ограниченного сверху множества ⇒ х ≤ y, ∀x ∈ X, ∀y ∈ Y
Bp аксиомы непрерывности ℝ ⇒ ∃с ∈ ℝ; x ≤ c ≤ y, ∀x ∈ X, ∀y ∈ Y
Следовательно, с = sup X

Единственность, если с и с' = sup X ⇒ с ≤ с' и с' ≤ c ⇒ c = c'
