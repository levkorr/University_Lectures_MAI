Множество, элементами которого являются множества, называются **семейством множества**

$\{\Omega_{\alpha}\}_{\alpha \ ∈  \ A}$ 

$\underset{\alpha \ ∈ \ A}{\cup} \ \Omega_{\alpha}-$ **объединение множеств семейства**

$x∈\underset{\alpha \ ∈ \ A}{\cup} \ \Omega_{\alpha}⇔∃ \alpha ∈A: x∈\Omega_{\alpha}$ 

$\underset{\alpha \ ∈ \ A}{\cap} \ \Omega_{\alpha}-$ **пересечение множеств семейства**

$x ∈ \cap \ \Omega_{\alpha}⇔x ∈  \Omega_{\alpha}, ∀\alpha ∈A$

Индексировать $-$ задать функцию: $A→$ семейство $\Omega$ 
$\alpha ↦$ элемент семейства $\Omega_{\alpha}$

Пусть $\{I_{k}\} = [a_{k},b_{k}), k = 1,2, ...$ 
$\{I_{k}\}_{k \ ∈ \ ℕ} \ -$  семейство отрезков числовой прямой. Оно называется **семейством вложенных отрезков**, если $I_{k-1}⊂I_{k}, ∀k=1,2,...$ 

Семейство  $\{\Omega_{\alpha}\}_{\alpha \ ∈ \ A}$ называется **покрытием множества** $Y$, если $Y ⊂ \underset{\alpha \ ∈ \ A}{\cup} \Omega_{\alpha}$ 

Пусть $a ∈ℝ$, интервал $(a-\delta;a+\delta)$, где $\delta>0$, **называется δ-окрестность** **точки $a$** и обозначается $U_{\delta}(a)$ 

Точка a называется предельной точкой множества $Y ⊂ ℝ$, если для  $∀\delta>0$ выполняется $U_{\delta}(a) \cap Y -$ бесконечное множество
